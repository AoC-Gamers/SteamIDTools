# Instalacion

El ZIP es un toolkit de includes para compilacion. No requiere procesos,
puertos, tokens ni extensiones. La instalacion en un proyecto ocurre al copiar
los includes y recompilar sus consumidores. La entrega de esos consumidores
al gameserver requiere su propio alcance y validacion.

Ver [migracion](migration.md) para instalaciones que ya tengan el SMX HTTP.
Quitar una carga del CFG o un archivo del ZIP no elimina binarios antiguos.
