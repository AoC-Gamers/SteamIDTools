# Inicio

Copiar `steamidtools.inc`, `steamidtools_stock.inc` y `steamidtools_helpers.inc`
desde `sourcemod/scripting/include/` a los includes de compilacion del consumidor.
Usar `#include <steamidtools>` y recompilar el plugin consumidor.
No instalar un plugin SteamIDTools ni configurar servicios HTTP.

Ver [conversiones](sourcemod.md), [migracion](migration.md) y
[build](build-system.md).
