# Pendientes SteamIDTools

La implementacion offline 3.0.0 se valida localmente. El backend anterior se
conserva en la rama local `codex/archive-http-backend`. La guia estable de
migracion esta en [docs/migration.md](docs/migration.md).

- Aceptacion SRCDS de los consumidores migrados, solo con un encargo operativo.
- Entrega coordinada de includes y consumidores, retirada del SMX/CFG HTTP ya
  instalados y eventual parada de un backend desplegado, con autorizacion propia.
- Migracion de BanSystem-Legacy si se encarga; conserva su API e includes 2.x.
- Publicacion de repositorios y releases solo cuando se solicite.
